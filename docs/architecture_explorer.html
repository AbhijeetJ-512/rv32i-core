    How to read the wires

    • Everything inside rv32i_core is synchronous to one clock. A solid wire is combinational and settles within the cycle; the pipeline registers (tall bars) latch on the rising edge.
    • There is no asynchronous messaging, no bus protocol and no retry loop in this design. The memories answer in the same cycle with no wait states, so nothing ever waits on a response.
    • The two recovery mechanisms are a one-cycle load-use stall (replay the ID instruction) and a redirect from EX that repairs a mispredicted or unpredicted control transfer by flushing the younger instructions.
    • Errors are traps. ECALL, EBREAK, an illegal encoding, a misaligned load/store or a misaligned branch/jump target stop the core: there are no CSRs and no trap vector.
    • FWD_PRECOMP changes where the forwarding compare happens (ID and registered, or EX), not what it selects; the model here uses the EX rule, which the checker asserts both variants obey.
